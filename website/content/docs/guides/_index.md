**Concepts** explains how Corium works and why it is shaped this way. **Quick
start** gets a node running. **Upgrades** moves it to a new image without losing
quorum. The rest are task pages: Cilium, software RAID, building your own image,
and a WireGuard overlay between hosts. **Troubleshooting** indexes failures by
symptom.
