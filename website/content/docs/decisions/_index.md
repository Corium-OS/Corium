These record architectural decisions and the reasoning behind them. You do not
need any of them to use Corium — they exist so that a choice can be revisited
knowing what it cost, and so that a contributor can tell a settled decision from
an accident.

The sequence skips 7: that record was drafted for ZFS data disks and never
merged.
